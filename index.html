联屏PaneWall

把散落各处的直播源收拢成一面墙 —— 单文件播放器，免安装、离线可用。

  • 导入自己的 m3u
  • 多画面墙
  • 实时字幕与翻译
  • 截图 / 录像 / 录音
  • 不内置任何频道源
进入应用Open
在线版的限制：本页走 https，网页在 https 下加载 http 的流会被浏览器当成「混合内容」拦掉 —— 这是浏览器的安全策略，不是工具的问题，而很多直播源恰恰是 http。 所以在线版适合试玩和分享；真要日常看，请到 GitHub 仓库把 web/PaneWall.html 下载下来双击打开，本地没有这条限制。
